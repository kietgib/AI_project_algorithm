📊 So sánh thuật toán BFS & DFS trên 8-Puzzle

Breadth-First Search (BFS)

  • Cấu trúc: Hàng đợi FIFO (First In First Out).
  • Tính tối ưu: Đảm bảo tìm ra đường đi ngắn nhất (ít bước nhất) vì duyệt theo từng tầng độ sâu.
  • Độ phức tạp bộ nhớ: Rất lớn \(O(b^d)\), Frontier lưu trữ toàn bộ các node ở tầng biên.
  • Phù hợp: Khi cần lời giải tối ưu và độ sâu nghiệm không quá lớn.

Depth-First Search (DFS)

  • Cấu trúc: Ngăn xếp LIFO (Last In First Out).
  • Tính tối ưu: Không đảm bảo tối ưu, có thể tìm thấy đường đi rất dài và vòng vèo.
  • Độ phức tạp bộ nhớ: Tiết kiệm hơn BFS trên cây tìm kiếm \(O(b \cdot m)\).
  • Lưu ý: Trên đồ thị 8-Puzzle cần lưu `explored` để tránh lặp vô tận (infinite loop).

Trần Gia Kiệt - 24110103
Bài tập trên lớp thực hành viết 9 hàm trên BFS & DFS

from collections import deque

# 1. Lớp Node
class Node:
    def __init__(self, state, parent=None, path_cost=0, action=None):
        self.state = state
        self.parent = parent
        self.path_cost = path_cost
        self.action = action

# 2. Hàm kiểm tra đích (is_goal)
def is_goal(node, goal_state):
    return node.state == goal_state

# 3. Hàm khởi tạo hàng đợi (BFS) / ngăn xếp (DFS)
def create_queue():
    return deque()

# 4. Hàm thêm phần tử (enqueue / push)
def enqueue(frontier, node):
    frontier.append(node)

# 5. Hàm lấy phần tử (dequeue - BFS / pop - DFS)
def dequeue(frontier):
    return frontier.popleft()  # BFS dùng popleft; DFS dùng pop()

# 6. Hàm kiểm tra hàng đợi rỗng
def is_empty(frontier):
    return len(frontier) == 0

# 7. Hàm sinh nút con (expand)
def expand(node):
    children = []
    state = node.state
    zero_index = state.index(0)
    row = zero_index // 3
    col = zero_index % 3

    actions = [
        (-1, 0, "UP"),
        (1, 0, "DOWN"),
        (0, -1, "LEFT"),
        (0, 1, "RIGHT")
    ]

    for dr, dc, act_name in actions:
        new_row = row + dr
        new_col = col + dc
        if 0 <= new_row < 3 and 0 <= new_col < 3:
            new_index = new_row * 3 + new_col
            new_state = list(state)
            new_state[zero_index], new_state[new_index] = new_state[new_index], new_state[zero_index]
            new_state = tuple(new_state)

            child = Node(
                state=new_state,
                parent=node,
                path_cost=node.path_cost + 1,
                action=act_name
            )
            children.append(child)
    return children

# 8. Hàm truy vết lời giải (trace_solution)
def trace_solution(node):
    path = []
    while node is not None:
        path.append(node.state)
        node = node.parent
    path.reverse()
    return path

# 9. Lớp định nghĩa bài toán (Problem)
class Problem:
    def __init__(self, initial_state, goal_state):
        self.initial_state = initial_state
        self.goal_state = goal_state

    def is_goal(self, node):
        return is_goal(node, self.goal_state)

    def expand(self, node):
        return expand(node)
